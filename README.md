# 돌이전쟁: 카드
## 규칙 엔진 구현판

현재 메인 브랜치는 단순 v0.1 데모가 아니라 **구성 → 전투 → 구매 → 다음 구성**을 반복하는 상태 기반 엔진을 사용한다.

### 핵심 루프
1. 캐릭터 더미에서 플레이어당 26장 비공개 배분
2. 최고 별 공개 → 동률이면 재추첨 반복 → 초기 행동 순서 확정
3. 캐릭터 구성: 전장 최대 5장 / 덱 최대 20장 / 예비 1장 이상
4. 지도자 1장 별도 선택
5. 전투: 초기 순서대로 한 번에 한 카드 행동
6. 처치 시 별 수만큼 코인
7. 한 플레이어만 생존하면 승점 +1, 코인 +5
8. 초기 순서대로 구매
9. 구매 종료 후 다시 캐릭터 구성
10. 승점 5점 즉시 종료

### 구현된 시스템
- 47종 일반 캐릭터 카드
- 15종 아이템
- 8종 지도자와 고유 스킬 선택
- 캐릭터/아이템/지도자 유한 더미
- 상태효과: 기절, 화상, 출혈, 독, 피폭, 무적, 보호막, 피해감소, 공격력감소, 반사, 다음 피해 무효, 관통, 랜덤 대상
- 카드별 쿨타임
- 지도자별 조건부 패시브
- 지도자 교체/구매
- 아이템 실제 사용 및 수량 감소
- PvP / PvE
- 반응형 고급 UI

### 명시적으로 잠근 규칙
- 피폭은 제거 가능한 디버프가 아니며 영구 지속
- 독의 피격 추가 피해 +1은 중첩되지 않음
- 부활은 기본 HP로 복귀
- 아이템 구매는 구매 단계당 최대 3회
- 캐릭터 구매 카드는 예비 카드로 들어가 다음 구성에서 사용
- 지도자 구매 카드는 다음 구성에서 교체 가능
- 쿨타임은 라운드 종료마다 감소
